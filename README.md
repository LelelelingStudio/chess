# Chess

A modern, welcoming chess experience from **Lelele Games**.

The project aims to make chess feel clear and enjoyable for both new and experienced players, with a polished interface, friendly visuals, and support for different ways to play.

## Planned Features

- **Local play** — play a game with someone sharing your device.
- **Play against the computer** — choose from different difficulty levels.
- **Online play** — invite another player to a game.
- **Classic chess rules** — including castling, en passant, pawn promotion, check, and checkmate.
- **English and Simplified Chinese** — switch the interface language.
- **Responsive design** — designed for desktop, tablet, and mobile screens.
- **A playful visual style** — a warm chessboard, rounded pieces, and custom capture animations.

> This project is currently in development. The features above describe the intended direction and may not all be available yet.

## Getting Started

This is a browser-based project and does not require a build step.

For local development, serve the project folder with any simple static web server, then open the local address in a modern browser. Serving the files over HTTP is recommended because the game uses JavaScript modules.

## Project Status

Early development. The interface and core game experience are being built in stages.
